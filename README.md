# Adidas-Sales-Dashboard-
This Power BI project provides a comprehensive analysis of Adidas sales performance across multiple dimensions, including regions, products, retailers, sales methods, and time periods.

Project:

ADIDAS SALES DASHBOARD


Project Highlights

Sales Performance Analysis

Profitability Tracking

Regional Comparison

Product-wise Analysis

Retailer Performance Evaluation

Interactive Filtering and Drill-down Capability

Geographic Sales Visualization



KPIs Included

Total Sales

Total Profit

Units Sold

Profit Margin

Price Per Unit



Technologies Used

Power BI Desktop

Power Query

DAX

Data Modeling

Dashboard Insights



The dashboard enables stakeholders to monitor sales trends, identify top-performing regions and products, evaluate retailer contributions, and make data-driven business decisions.
